Консольное приложение для управления коллекцией туристических маршрутов с поддержкой XML-сериализации.

## Возможности

- Добавление, просмотр, поиск и удаление маршрутов
- Фильтрация по расстоянию
- Автоматическое сохранение данных в XML
- Поддержка двух CLI интерфейсов: argparse и click
- Статистика по маршрутам

## Требования

- Python 3.8+
- Зависимости: (pytest,flake8,black,isort,mypy)

## Особенности проекта
- Реализация взаимодействия с помощью CLI
- Готовые команды для упрощенной пользовательской работы
- Раздел help для помощи при заторе
